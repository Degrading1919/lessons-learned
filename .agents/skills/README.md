# Lessons Learned Agent Skills

## lessons-learned-recorder

Path: `lessons-learned-recorder/SKILL.md`

Use whenever an agent audits project history, adds or revises a model/tool case, documents prompt evolution, reconciles personal results with public benchmarks, or updates the machine-readable evidence corpus.

The skill exists to prevent two failure modes:

1. turning the repository into an unsourced model leaderboard;
2. recording only successful artifacts while losing the prompt, user reaction, failures, cost, and later corrections that make the evidence useful.
